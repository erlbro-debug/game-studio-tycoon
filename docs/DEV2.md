## Шаг 1. Подготовка (один раз, 15 минут)

1. Зарегистрируйся на https://github.com (если ещё нет) и отправь свой логин владельцу.
2. Владелец добавит тебя: репозиторий → Settings → Collaborators. Прими приглашение на почте.
3. Открой https://github.com/ButherWoW/game-studio-tycoon — нажми **Watch → All Activity**, чтобы видеть новые задачи и обновления.
4. Установи приложение GitHub на телефон — удобно отвечать на задачи.

## Шаг 2. Как работать с задачами

- **Что-то придумал / нашёл баг** → Issues → **New issue** → шаблон «Новая механика» или «Баг».
- **Ответ для Dev 1** (список жанров, цены, отзыв) → пиши комментарием в нужной задаче.
- **Хочешь поменять число** (цену, время разработки) → открой файл в `src/shared/Config` на GitHub → значок карандаша ✏️ → поменяй → **Commit changes** → выбери «Create a new branch and start a pull request». Claude проверит в Studio.
- Метки задач: `balance` (цифры), `ui` (интерфейс), `building` (модели), `bug`, `good first issue`.

## Шаг 3. Как проверять результат (без запуска игры)

Тестирует только Claude. После каждой задачи он присылает в Issue **«Отчёт #N»**: что сделано, скриншоты из Studio, что проверено и какие числа получились (время разработки игры, сколько денег за релиз и т.п.). Ты отвечаешь в этом Issue:
1. Совпадает ли с тем, что задумывали? Что поменять?
2. Не слишком ли быстро / медленно (время, цены, награды)?
3. Как выглядит: нравится ли стиль, понятен ли интерфейс по скриншотам?
4. Что делать дальше — какую задачу брать следующей.
